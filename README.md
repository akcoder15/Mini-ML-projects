# 🤖 Machine Learning & Data Analytics Portfolio

A collection of end-to-end machine learning implementations and exploratory data analytics projects built using **Python**, **Scikit-Learn**, **Pandas**, and **NumPy**. This repository demonstrates practical implementations across supervised classification, unsupervised clustering, feature engineering, and natural language preprocessing.

---

## 📌 Featured Projects Overview

| Project | Type | ML Paradigm | Algorithm / Tech Stack | Key Objective |
| :--- | :--- | :--- | :--- | :--- |
| **Heart Disease Detection** | Medical Diagnosis | Supervised Classification | K-Nearest Neighbours | Predict heart disease presence from clinical metrics. |
| **Loan Default Prediction** | Financial Risk | Supervised Classification | Decision Trees | Identify high-risk loan applicants using financial indicators. |
| **Customer Segmentation** | Retail Analytics | Unsupervised Clustering | K-Means Clustering, PCA | Group retail customers based on age, income, and spending scores. |
| **Spam Mail Classifier** | Text Processing | NLP Classification | Logistic Regression, TF-IDF Vectorization | Classify incoming email messages as Spam or Ham. |
| **Iris Flower Classification**| Benchmark ML | Multi-class Classification| Logictic Regression | Multi-class feature-based botanical classification. |
